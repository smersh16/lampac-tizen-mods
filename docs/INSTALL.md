# Phantom и Mirage на телевизорах Samsung (Tizen): установка

## Зачем это нужно

Модули Phantom и Mirage отдают видео в формате HLS на fMP4 (файлы `.m4s`). Телевизор Samsung с Tizen такой формат не проигрывает: показывает первый кадр и висит на «Загрузка».

Исправленные модули `PhantomTs` и `MirageTs` на лету пересобирают видео в обычный MPEG-TS. Перекодирования нет, нагрузка на сервер маленькая. Определяют телевизор по `User-Agent` (в нём есть `Tizen` или `SMART-TV`). Компьютеры и телефоны получают поток как раньше.

Что нужно знать заранее:

- На телевизоре будет максимум **1080p**. Поток 2160p закодирован в AV1, и телевизор его не декодирует (будет звук без картинки). Для ПК и телефонов 4K остаётся.
- Инструкция для **Lampac в Docker** (docker compose). Если у вас установка без Docker, шаги похожи, но пути другие.

## Что понадобится

- Доступ к серверу, где работает Lampac (по SSH или напрямую), и права запускать `docker`.
- Папки модулей из этого репозитория: `mods/PhantomTs` и `mods/MirageTs` (скачайте репозиторий: **Code → Download ZIP**, или клонируйте через git).
- Рабочий Lampac, в котором модули Phantom и/или Mirage уже включены. Нужен только тот модуль, который вам нужен: можно ставить один из двух.

ffmpeg отдельно ставить не нужно, он уже есть внутри образа Lampac.

## Шаг 1. Найдите папку с docker-compose.yaml

Папка, в которой лежит файл `docker-compose.yaml` вашего Lampac, называется ниже «папка Lampac». Узнать её можно командой:

```
docker inspect lampac --format '{{ index .Config.Labels "com.docker.compose.project.working_dir" }}'
```

Перейдите в неё: `cd /путь/из/вывода`.

В примерах ниже данные Lampac лежат в `./lampac-docker/` (там `init.conf` и `passwd`). Если у вас другое расположение, используйте свои пути.

## Шаг 2. Положите модули в папку mods

1. Создайте на сервере папку для сторонних модулей:
   ```
   mkdir -p ./lampac-docker/mods
   ```
2. Скачайте репозиторий (**Code → Download ZIP**), распакуйте и скопируйте на сервер **содержимое папки `mods`** из репозитория, то есть две папки `PhantomTs` и `MirageTs`, в `./lampac-docker/mods/` (например, через WinSCP, `scp` или файловый менеджер).
3. Проверьте результат:
   ```
   ls ./lampac-docker/mods
   ```
   Должно быть две папки: `PhantomTs` и `MirageTs`. В каждой лежат файлы `Controller.cs`, `ModInit.cs`, `Remux.cs`, `manifest.json` и другие.

Если вам нужен только один модуль, положите только его.

## Шаг 3. Подключите папки к контейнеру (docker-compose.yaml)

Откройте `docker-compose.yaml` любым редактором (`nano docker-compose.yaml`). В разделе `volumes` сервиса lampac добавьте строки со своими модулями. Остальные строки не трогайте.

Пример:

```yaml
    volumes:
      - ./lampac-docker/config/passwd:/lampac/passwd
      - ./lampac-docker/config/init.conf:/lampac/init.conf
      - ./lampac-docker/mods/PhantomTs:/lampac/mods/PhantomTs
      - ./lampac-docker/mods/MirageTs:/lampac/mods/MirageTs
```

Важно:
- Пробелы в начале строк должны совпадать с соседними строками (в YAML отступы значимы). Табуляцию не используйте.
- Пути слева от двоеточия должны совпадать с тем, куда вы положили папки на шаге 2. Справа оставьте как в примере.

## Шаг 4. Выключите встроенные Phantom и Mirage (init.conf)

Если оставить оба варианта, они конфликтуют. Поэтому встроенные нужно отключить.

Откройте `init.conf` (в примере это `./lampac-docker/config/init.conf`) и найдите раздел `BaseModule`. Если его нет, добавьте. В список `SkipModules` добавьте `"Phantom"` и `"Mirage"`. **Не удаляйте имена, которые там уже есть**: по умолчанию там выключены Catalog, DLNA, JacRed, Sync, TimeCode, TorrServer, Tracks, Transcoding, WebLog. Если список затереть, эти модули включатся.

Пример:

```json
"BaseModule": {
  "SkipModules": [
    "Catalog", "DLNA", "JacRed", "Sync", "TimeCode",
    "TorrServer", "Tracks", "Transcoding", "WebLog",
    "Phantom", "Mirage"
  ]
}
```

Если ставите только один модуль, добавьте в список только его встроенное имя.

Следите за запятыми: между элементами и разделами запятые обязательны, после последнего элемента не нужна. Если Lampac после этого не стартует, скорее всего, ошибка именно здесь. Проверить файл можно на сайте jsonlint.com (не вставляйте туда пароли и токены).

Если `BaseModule` в файле уже есть, не создавайте второй такой же раздел, а дополните существующий.

Настройки самих модулей остаются в разделах `"Phantom"` и `"Mirage"` в `init.conf`, как и раньше. Менять их имена не надо.

## Шаг 5. Перезапустите Lampac

В папке Lampac:

```
docker compose up -d --force-recreate
```

Подождите 1-2 минуты, пока Lampac стартует и скомпилирует модули.

## Шаг 6. Проверьте, что модули загрузились

```
docker logs lampac 2>&1 | grep -iE "compilation|loaded module: (phantom|mirage)"
```

Нужный результат:
- строки вида `skip compilation module: Phantom` и `skip compilation module: Mirage` (встроенные пропущены);
- строки `loaded module: PhantomTs` и/или `loaded module: MirageTs` (в логе регистр может быть другой, например `PhantomTS`);
- **нет** строк `error compilation ...`.

Если есть `error compilation`, смотрите раздел «Если что-то не работает».

## Шаг 7. Проверьте на телевизоре

1. Откройте Lampa на телевизоре (виджет Samsung).
2. Выберите фильм, источник Phantom или Mirage, запустите.
3. Должна появиться картинка со звуком, перемотка должна работать. Качество будет 1080p.

Первые секунды у Mirage могут быть дольше обычного: он сначала запускает невидимый браузер и дожидается первых сегментов.

## Настройки (необязательно)

Добавляются в `init.conf` в разделы `"Phantom"` и `"Mirage"`. Обычно менять ничего не нужно.

| Параметр | Значение по умолчанию | Что делает |
|---|---|---|
| `remux_ts` | `true` | Включает пересборку в TS. `false` отключает её полностью. |
| `remux_ua` | `"Tizen\|SMART-TV\|SmartTV"` | Каким устройствам отдавать TS (регулярное выражение по `User-Agent`). Пустая строка `""` означает всем. Для телевизоров LG можно добавить `\|Web0S`. |
| `remux_maxq` | `1080` | Максимальное качество для устройств с TS. `0` снимает ограничение, но на телевизорах это вернёт «звук без картинки» на 4K. |
| `ffmpeg` | пусто | Путь к ffmpeg. Нужен только если ffmpeg лежит нестандартно. |
| `debug` | `false` | Включает диагностику в консоль (см. ниже). |

Пример:

```json
"Phantom": {
  "remux_maxq": 1080,
  "debug": false
},
"Mirage": {
  "enable": true,
  "debug": false
}
```

## Если что-то не работает

**Lampac не стартует или модули не загрузились.** Посмотрите ошибки:
```
docker logs lampac 2>&1 | grep -i "error" | tail -30
```
Частые причины: опечатка в `init.conf` (запятая, скобка), неверный путь в `docker-compose.yaml`, папка модуля называется не так (для Phantom должно быть именно `PhantomTs`, не `Phantom`).

**В логе `error compilation ...`.** Скопируйте строку ошибки целиком и отправьте мне, исправим код.

**Телевизор по-прежнему показывает первый кадр.** Включите `"debug": true` в разделе нужного модуля, перезапустите контейнер, запустите видео и выполните:
```
docker logs lampac 2>&1 | grep -E "Phantom video|Mirage video"
```
В строке должно быть `remux_ts=True`. Если там `False`, ваш телевизор не опознан: посмотрите `UA=...` в той же строке и добавьте характерное слово в `remux_ua`.

**В логе `ffmpeg не найден`.** Проверьте `docker exec lampac ls /lampac/data` и `docker exec lampac ffmpeg -version`. Если ffmpeg есть по другому пути, укажите его в параметре `ffmpeg`.

**Картинка есть, но видео «замирает» на 1440p/2160p.** Это нормально для телевизора: там AV1. Оставьте `remux_maxq` равным 1080.

**Mirage: ждёт долго или пишет, что нельзя открыть.** Mirage использует один скрытый браузер на весь сервер. Если одновременно смотреть разное с нескольких устройств, воспроизведение перезапускается. Смотрите по одному устройству.

**Не забудьте выключить отладку.** При `debug: true` в вывод `docker logs` попадают служебные токены Phantom. После проверки верните `false` и перезапустите контейнер, а логи с токенами никому не показывайте.

## Как вернуть всё назад

1. Уберите из `SkipModules` значения `"Phantom"` и `"Mirage"`.
2. Удалите добавленные строки `mods/...` из `docker-compose.yaml`.
3. Выполните `docker compose up -d --force-recreate`.

Папки с модулями можно оставить или удалить, на работу они уже не влияют.

## Важно помнить при обновлении Lampac

`PhantomTs` и `MirageTs` это копии встроенных модулей с доработками. Когда вы обновляете образ Lampac, встроенные Phantom и Mirage могут получить новые исправления (например, смену токенов и адресов источников), а ваши копии останутся прежними. Если после обновления Phantom или Mirage вдруг перестали находить фильмы, отключите наши копии по инструкции «Как вернуть всё назад» и проверьте, работают ли встроенные. Затем обратитесь за обновлённой версией доработанных модулей.
