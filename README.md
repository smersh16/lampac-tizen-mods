# lampac-tizen-mods

Доработанные модули **Phantom** и **Mirage** для [Lampac (lampac-nextgen)](https://github.com/lampac-nextgen/lampac), которые работают на телевизорах **Samsung (Tizen)**.

> Неофициальная доработка. К авторам Lampac проект отношения не имеет. Исходный код модулей принадлежит их авторам, здесь изменены только описанные ниже части.

## Какую проблему решает

Источники Phantom и Mirage отдают видео как HLS на fMP4 (файлы `.m4s`). Телевизор Samsung с Tizen такое видео не проигрывает: показывает первый кадр и висит на «Загрузка».

Модули `PhantomTs` и `MirageTs` на лету пересобирают fMP4 в обычный MPEG-TS через ffmpeg (`-c copy`, без перекодирования). Телевизор определяется по `User-Agent` (`Tizen` или `SMART-TV`). ПК и телефоны получают поток как раньше.

На телевизоре качество ограничено **1080p**: поток 2160p закодирован в AV1, и телевизор его не декодирует. Для остальных устройств 4K остаётся.

## Что внутри

| Папка | Что это |
|---|---|
| `mods/PhantomTs` | Phantom: пересборка в TS, сохранение `Range` при запросах к CDN, лимит качества для ТВ |
| `mods/MirageTs` | Mirage: пересборка в TS поверх кеша Playwright, исправленные `Content-Type` и `Range`, лимит качества для ТВ |
| `docs/INSTALL.md` | Подробная инструкция по установке (Docker) |

## Быстрый старт

**Способ А. Автоматически через `repository.yaml` (рекомендуется).** Lampac сам скачает модули из GitHub при запуске и обновит при следующих запусках:

1. Создайте файл `mods/repository.yaml` с таким содержимым (готовый пример лежит в корне репозитория):

   ```yaml
   - repository: https://github.com/smersh16/lampac-tizen-mods
     branch: main
     modules:
       - mods/PhantomTs
       - mods/MirageTs
   ```

2. Добавьте `"Phantom"` / `"Mirage"` в `SkipModules` в `init.conf`.
3. Перезапустите контейнер. Модули появятся в `module/lampac-tizen-mods/`.

**Способ Б. Вручную.**

1. Скопируйте `mods/PhantomTs` и/или `mods/MirageTs` на сервер в `./lampac-docker/mods/`.
2. Подключите папки в `docker-compose.yaml` и добавьте `"Phantom"` / `"Mirage"` в `SkipModules` в `init.conf`.
3. Пересоздайте контейнер: `docker compose up -d --force-recreate`.

Подробности, примеры и разбор проблем: [docs/INSTALL.md](docs/INSTALL.md).

## Настройки

Добавляются в разделы `"Phantom"` и `"Mirage"` в `init.conf`.

| Параметр | По умолчанию | Описание |
|---|---|---|
| `remux_ts` | `true` | Включить пересборку в TS |
| `remux_ua` | `Tizen\|SMART-TV\|SmartTV` | Каким устройствам отдавать TS (регулярное выражение по `User-Agent`) |
| `remux_maxq` | `1080` | Максимальное качество для таких устройств, `0` без ограничения |
| `ffmpeg` | пусто | Путь к ffmpeg, если он лежит нестандартно |
| `debug` | `false` | Диагностика в консоль (содержит служебные токены, после проверки выключайте) |

## Состояние проекта

Проверено на телевизоре Samsung с Tizen 6.0. Код написан для Lampac из репозитория `lampac-nextgen/lampac`; при обновлении Lampac встроенные модули могут измениться, а эти копии нужно обновлять отдельно.

## Безопасность

Не публикуйте свои `init.conf`, `passwd` и логи: в них могут быть пароли и токены. Эти файлы исключены через `.gitignore`.
