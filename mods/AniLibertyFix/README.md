# AniLibertyFix

Доработанный встроенный модуль **AniLiberty** (раздел `"AniLiberty"` в `init.conf`, маршрут `lite/aniliberty`).

## Что исправлено

- **Сезоны путались.** Номер сезона у серий (`s`) определялся по названию и `alias`, поэтому у «Революция книжного червя: Приёмная дочь лорда» получался сезон 1 и подтягивались названия и иконки первого сезона. Теперь номер считается по франшизе: позиция среди TV-релизов в `GET /api/v1/anime/franchises/release/{id}` (по `sort_order`). Если франшиза не найдена, релиз не TV или запрос не удался, работает прежняя эвристика.
- **Неверные созвучные аниме.** API AniLiberty ищет нечётко. Раньше при отсутствии совпадений по началу названия модуль показывал все результаты API. Теперь показываются только релизы, у которых `main`, `english` или `alternative` начинается с запроса. Все результаты доступны через режим `similar`.
- Ключи кеша `aniliberty:search2:` и `aniliberty:release2:` (старые записи не мешают).

## Установка

Как у остальных модулей репозитория: добавьте `mods/AniLibertyFix` в `repository.yaml` и `"AniLiberty"` в `SkipModules` (раздел `BaseModule` в `init.conf`). См. [docs/INSTALL.md](../../docs/INSTALL.md).

Настройки те же, что у встроенного модуля (`displayindex`, `stream_access`, `httpversion` и т.д.).

## Проверка

```bash
docker logs lampac 2>&1 | grep -iE "error compilation|loaded module: anilib"
```

Номер сезона в ответе: у серий релиза 10165 должно быть `"s":4`.

## Ограничения

Порядок франшизы AniLiberty может не совпадать с нумерацией TMDB (спин-оффы, ONA, спецвыпуски). Для сравнения источник нумерации у модуля один — `sort_order` TV-релизов.
